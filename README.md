# 🚗 Adaptive Wheel Alignment System for Vehicles — ML-Based Dynamic Camber & Toe Angle Optimization

Welcome to the official repository of our ME 325 Mechanical Engineering Group Project from the University of Peradeniya. This project explores a machine learning-driven solution to real-time vehicle wheel alignment, with a focus on enhancing cornering grip, ride comfort, and vehicle stability through adaptive control of camber and toe angles.

# 📌 What This Project Offers

## 🔧 Dynamic Simulation-Driven Model
Built using CarSim and MATLAB Simulink, we modelled vehicle dynamics and collected high-fidelity data to understand the impact of wheel alignment on handling and safety.

## 🧠 Machine Learning Integration
We implemented a Random Forest Regressor trained on simulation data to predict optimal camber angles under varying driving conditions (cornering, speed, road surface, etc.).

## 📊 Validation with Physics-Based Equations
Model predictions were verified using a validated dynamic vehicle equation to assess understeer and camber performance — enhancing credibility and realism.

## 🧪 Tested in Real-Time Simulation
Adaptive control loops adjust camber angles in real-time within a virtual environment, significantly reducing understeer and improving stability.

# 🚀 Key Features

    - 🔄 Real-time camber prediction for adaptive wheel alignment
    - 🔬 Simulation-based data generation using CarSim
    - 🤖 Randomized hyperparameter tuning for precision ML modeling
    - 📉 Low Mean Absolute Error (MAE) and high R² accuracy
    - 🛞 Demonstrated improvement in vehicle grip and reduced body roll
    - 🔧 Designed to be cost-effective and scalable for non-luxury vehicles

# 💡 Why It Matters

Conventional alignment systems are static and cannot adapt to dynamic conditions like turns or uneven roads. Our project brings intelligence to suspension systems by predicting optimal alignment settings, bridging the gap between classical dynamics and modern machine learning. The system can be a blueprint for future smart suspension technologies in affordable vehicles.
