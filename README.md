🚗 #Adaptive Wheel Alignment for Vehicles
This repository features a simulation-based, machine learning-driven system for adaptive wheel alignment, developed for the ME325 Mechanical Engineering Group Project, University of Peradeniya.

##What is it?
Most vehicles use passive, fixed wheel alignment, which can’t adjust to changing road and driving conditions—limiting cornering grip, safety, and efficiency. This project introduces a cost-effective alternative: a controller that predicts and dynamically adjusts camber and toe angles in real time using sensor data and a trained Random Forest machine learning model. The goal: maximize vehicle stability and cornering performance across varied scenarios.

##Key Features
Real-time Machine Learning Prediction: Uses a Random Forest regressor trained on extensive CarSim simulation data to estimate optimum camber and toe settings based on real driving inputs (e.g., tire slip, vehicle speed, steering angle).

Simulation-Driven Design: Built and validated with industry-standard simulators (CarSim, MATLAB/Simulink), ensuring realistic and scalable results.

Performance Validation: Demonstrates significant reduction of understeer and improved stability using both ML and mathematical vehicle dynamics models.

Ready for Future Integration: Architecture supports expansion to hardware/sensor integration in real vehicles.

Transparent & Reproducible: Full project proposal, methodology, data preprocessing scripts, model training notebooks, and evaluation metrics (MAE, R²) included.

##Contents
Project Proposal: Motivation, background, methodology, and literature review.

Jupyter Notebook: End-to-end machine learning pipeline (data cleaning, feature selection, model training, tuning, evaluation, and prediction).

Sample Data & Results: Simulation parameters, test cases, and output plots.

Documentation: Clear instructions for reproducing results or adapting to your needs.

##Why it matters
By bridging mechanical engineering and machine learning, this project explores how smart, adaptive chassis technologies can be made accessible and practical—not just for high-end cars, but for conventional vehicles too. The result: improved driving safety and performance powered by data-driven intelligence.
